Connect Telegram
  1. Message @BotFather, use /newbot and copy the token.
  2. Copy .env.example to .env in this project. Set TELEGRAM_BOT_TOKEN. Keep it private.
  3. Message your new bot /start. Stop Vitool, then run uv run vitool --telegram-chats.
  4. Set TELEGRAM_CHAT_ID in .env and restart with uv run vitool.
  5. Send a test here. Use /help in Telegram to change settings from your phone.
